
# Nexus AI — AI-Powered Workspace

Build a premium, production-ready AI workspace prototype inspired by Notion, NotebookLM, and Linear. The app will feature rich sample data, polished animations, and enterprise-grade design.

## Tech Stack

| Layer           | Technology                          |
| --------------- | ----------------------------------- |
| Framework       | Next.js 15 (App Router, TypeScript) |
| Styling         | Tailwind CSS v4                     |
| Components      | Shadcn UI                           |
| Charts          | Recharts                            |
| Animations      | Framer Motion                       |
| Drag & Drop     | @dnd-kit                            |
| Knowledge Graph | react-force-graph-2d                |
| Icons           | Lucide React                        |
| Date Handling   | date-fns                            |

---

## User Review Required

> [!IMPORTANT]
> **Scope**: This is a **frontend prototype** with realistic sample data and simulated AI interactions. There is no real backend, AI model, or email sending. All AI responses, document summaries, and email drafts are pre-built sample data that simulate production behavior.

> [!IMPORTANT]
> **Dark Mode**: The spec mentions both a "clean white/light theme" and "dark mode support". I will implement both with a theme toggle, defaulting to the **light theme**.

> [!WARNING]
> **This is a very large build.** I will implement it in a phased approach, building the full application in one pass but prioritizing structural completeness and visual polish. Some advanced interactions (e.g., actual drag-and-drop block editing, real PDF parsing) will be simulated.
